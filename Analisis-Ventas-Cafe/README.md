# 📊 Dashboard de Ventas de Café 2024–2025 – Power BI

Proyecto desarrollado en **Power BI** que analiza las **ventas de café de los últimos dos años**, con un enfoque interactivo y orientado a la toma de decisiones.

---

## 🎯 Objetivo
Diseñar un tablero **interactivo, claro y escalable**, que permita comprender fácilmente la evolución y comportamiento de las ventas.

---

## 📌 ¿Qué incluye este dashboard?
- 📅 Segmentación por **año, tipo de café y momento del día**  
- 💰 **KPI clave**: ventas totales, ticket promedio y variación interanual  
- 📈 Análisis visual de **tendencias y productos más demandados**  

---

## 🛠️ Tecnologías y proceso aplicado
- 🗂️ **Generación de datos ficticios** para simular un caso real  
- 🛠️ **Modelado de datos** en esquema estrella  
- 🧮 **Creación de medidas DAX** para análisis dinámico  
- 🎨 **Diseño visual optimizado** para análisis rápido y toma de decisiones  

---

## 🚀 Público objetivo
Este dashboard es ideal para:  
- Áreas de **ventas y marketing**  
- **Inteligencia de negocios (BI)**  
- **Planeamiento estratégico y comercial**
